# Reeden 小工具

給 Reeden 閱讀 App 使用者的小工具合集，透過 GitHub Pages 發布：
https://reeden-tools.github.io/

| 工具 | 網址 | 說明 |
|---|---|---|
| Reeden SVG 工坊 | https://reeden-tools.github.io/svg-studio/ | 製作閱讀頁的 SVG 疊加層，即時模擬 App 顯示，複製 code 貼進 Reeden |

## 新增工具

每個工具放在自己的資料夾（例如 `svg-studio/index.html`），再到根目錄的 `index.html` 加一張卡片。
